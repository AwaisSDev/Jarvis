# 🤖 Jarvis AI Assistant

Jarvis is a personal AI assistant built with **Python**.  
It can talk, listen, search, and help automate everyday PC tasks — your own local AI companion.

## 🚀 Features
- Voice recognition and speech response  
- Web automation & system control  
- AI chat and smart Q&A  
- Modular and easily customizable  

## 🛠️ Tech Stack
- Python  
- SpeechRecognition  
- pyttsx3  
- OpenAI / Groq API (optional)  

## ⚡ Future Plans
- Add local LLM support  
- GUI control panel  
- Offline task management
